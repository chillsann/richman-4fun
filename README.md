# 大富翁 4Fun · 复刻版

单文件网页版大富翁，零依赖、离线可玩。双击 `index.html` 即可开始。

**在线试玩**：https://chillsann.github.io/richman-4fun/

## 玩法系统

| 系统 | 说明 |
|---|---|
| 棋盘 | 48 格环形棋盘，7 个色组 × 4 块 = 28 块地产 |
| 地产 | 空地 → 木屋 → 洋房 → 大楼 → 摩天楼，5 个等级；集齐同色整组租金翻倍 |
| 骰子 | 每回合掷两颗骰子，经过起点领 $2,000 + 150 点数 |
| 点数 | 经过起点、事件获得，用于在道具店换道具、在土地庙祈福 |
| 道具 | 12 种：遥控骰子、路障、地雷、传送卡、均富卡、购地卡、拆迁卡、免费卡、换地卡、转向卡、乌龟卡、天使卡 |
| 神仙 | 财神 / 土地公 / 福神 / 天使 / 穷神 / 衰神，附身 4 回合，各有明示效果 |
| 股票 | 4 支股票，每回合随机波动，买卖赚差价，市值计入总资产 |
| 银行 | 存款每回合 5% 利息（钱夫人 10%），存款不受均富卡和查税影响 |
| 新闻 | 11 条全局新闻：降息、房市调控、通胀、慈善晚宴、城市改建等 |
| 特殊格 | 税务局（10% 现金进奖池）、停车场（领奖池）、监狱、医院、土地庙、道具店、证券交易所、银行 |
| 角色 | 6 位，各带专属特技（折扣 / 加租 / 减租 / 利息 / 抗伤 / 捡道具） |
| 破产 | 现金不足时依次卖股票 → 取存款 → 八折变卖地产 → 破产，地产归债主 |
| 胜负 | 淘汰制；40 回合后按总资产（现金 + 存款 + 股票 + 地产净值）排名 |

## 操作

- 点击骰子区的「掷骰子」或按空格出牌
- 点击右下道具栏使用道具（仅自己回合可点）
- 点击任意格子查看地价、租金表、特殊格说明
- 右下「银行 / 股票」按钮随时查看资产

## 开发

源码拆成三段，用 `build.mjs` 打包成单文件：

```
src/shell.html   页面骨架
src/style.css    样式
src/data.js      数据（棋盘、角色、道具、神仙、卡片、新闻、股票）
src/core.js      规则内核（回合、金钱、道具、神仙、股票、AI）
src/ui.js        界面（渲染、弹窗、交互、测试入口）

node build.mjs   → 生成 index.html（单文件，约 108 KB）
```

## 自测

| 参数 | 作用 |
|---|---|
| `?autotest=400` | 4 个电脑全自动对局，跑完把结果写进标题 |
| `?autotest=500&itemspam=1` | 每个电脑每回合拥有一切道具并强制使用，压测道具逻辑 |
| `?smoketest=1` | 模拟真人：自动点掷骰子、自动确认弹窗 |
| `?nofx=1` | 关闭所有动画（截图用） |
| `?preview=card/store/stock/over` | 直接打开对应界面（截图用） |

当前结果：常规对局 160 回合零异常；道具压测零异常；真人流程 80 回合零报错。
